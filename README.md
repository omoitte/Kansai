# 2027.02 오사카 · 간사이 가족여행 가이드

김포 출발 4인 가족여행 가이드입니다. 빌드 과정이 없는 정적 사이트로,
**USJ 포함 / 미포함 두 버전**을 서브 경로로 나눠 두었습니다.

## 주소 구조

| 경로 | 내용 |
|---|---|
| `/` | 선택 화면 — 두 버전 비교표와 설 연휴 안내 |
| `/usj/` | **USJ 포함 버전** — 닌텐도 월드·해리포터 공략 포함 |
| `/no-usj/` | **USJ 없는 버전** — 그 하루를 교토·고시엔·온천으로 |

쇼핑 체크리스트는 두 버전이 같은 저장소(`localStorage`의 `osaka2027.shopping`)를
쓰기 때문에, 한쪽에서 체크한 것이 다른 쪽에도 그대로 남습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 선택 화면 |
| `usj/index.html` | USJ 포함 버전 (전체 가이드) |
| `no-usj/index.html` | USJ 없는 버전 (전체 가이드) |
| `vercel.json` | Vercel 설정 — 빌드 없음, 캐시 즉시 만료 |

## 섹션

계획 · 공항(하루카 할인·패스) · 숙소(아파트형·온천) · 지역 · USJ ·
덴덴타운 · 근교(교토·고베·나라·고시엔) · 먹거리 · 쇼핑 체크리스트 ·
2월 · 일본어 · 준비

## 수정할 때

- **버전 문자열을 올리세요.** 각 파일 안 세 곳(`.ver-top`, `.ver`, `.footer`)에
  있습니다. 배포 반영 여부를 화면에서 바로 확인하는 용도입니다.
- `usj/`와 `no-usj/`는 내용이 거의 같습니다. 공통 부분을 고칠 때는
  **두 파일 모두** 고쳐야 합니다.
- 영업시간·요금은 2차 자료라 틀릴 수 있습니다. 확정 정보는 공식 사이트를 적어두세요.

## 배포

- **GitHub Pages** — Settings → Pages → Source: `Deploy from a branch`,
  Branch: `main` / `/ (root)`
- **Vercel** — 저장소 연결, Framework Preset은 **Other**
